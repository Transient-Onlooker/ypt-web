# 변경 기록

이 문서는 개발 버전의 사용자에게 보이는 변경과 검증 범위를 기록합니다. 버전 번호는 `package.json`과 일치합니다. 운영 배포 또는 GitHub Release를 뜻하지 않습니다.

## v0.6.0 · 과목별 시간 시각화 — 2026-09-26

- 오늘의 공부와 날짜별 기록에서 과목별 완료 시간을 막대로 비교할 수 있습니다. 앱에서 가져온 과목 색을 사용하고, 시간이 미확인인 과목에는 막대를 그리지 않습니다.
- [기능 후보 문서](feature-ideas.md)에 비공식 참조 클라이언트에서 찾은 아이디어와 실제 API 검증 필요 범위를 정리했습니다.
- 웹 구글 로그인은 로컬 토큰 교환 성공과 별개로 보류했습니다. 새 제공자 ID로 열품타 계정이 생성될 수 있고 기존 앱 본계정과 일치하는지 확인되지 않았습니다.

검증: 통합 테스트 14개, Pages 빌드, Worker 번들 검사 통과. 과목 시간 그래프의 실제 화면 육안 검사는 아직 수행하지 않았습니다.

## v0.5.1 · 타이머 인증 만료 처리 — 2026-09-26

- 타이머 시작·정지·복구 중 열품타 인증이 만료되면 현재 탭과 로그인 유지 세션을 함께 폐기하고 로그인 화면으로 돌아갑니다.
- 짧은 일시정지 뒤 열품타가 이전 시작 시각을 반환하는 경우, 웹도 해당 시각을 그대로 사용하는 회귀 검사를 추가했습니다. 15초 기록 합치기 동작 자체는 실제 계정으로 검증하지 않았습니다.

검증: 통합 테스트 14개, Pages 빌드, Worker 번들 검사 통과.

## v0.5.0 · 선택형 로그인 유지 — 2026-09-25

- Pages 로그인 화면에 **이 기기에서 로그인 유지** 옵션을 추가했습니다. 선택하면 서버가 별도 HttpOnly·Secure·Partitioned 쿠키를 발급해 새 탭에서도 세션을 복원합니다. 최대 유지 기간은 30일이며 로그아웃하면 연결된 세션을 폐기합니다.
- 쿠키가 차단된 브라우저에는 안내를 표시하고 현재 탭의 로그인은 유지합니다. 비밀번호와 열품타 JWT는 브라우저에 저장하지 않습니다.
- 출처 제한·CSRF 검사·계정 분리·쿠키 만료·로그아웃·열품타 인증 만료를 통합 테스트로 확인했습니다.

검증: 통합 테스트 13개, Pages 빌드, Worker 번들 검사와 운영 배포를 통과했습니다. 실제 브라우저에서 로그인 유지 선택 후 새 탭 재접속 시 세션 복원과 로그아웃 후 해제를 사용자 확인으로 검증했습니다.

## v0.4.1 · 비밀번호 관리자 연결 — 2026-09-25

- 로그인 성공 뒤 지원 브라우저의 비밀번호 관리자에 저장 제안을 요청합니다. 저장 여부는 사용자가 브라우저에서 결정하며, 지원하지 않거나 저장을 거부해도 로그인은 계속됩니다.

검증: Pages용 프론트 빌드와 기존 통합 테스트를 통과했습니다. 사용자가 운영 Pages 주소에서 실제 계정 로그인·타이머 시작·종료 성공을 보고했습니다. 브라우저별 비밀번호 저장 제안 화면은 확인하지 않았습니다.

## v0.4.0 · 로그인 기억하기 — 2026-09-25

- 로그인 화면에서 이메일 기억하기를 선택하면 해당 브라우저에 이메일만 저장합니다. 선택을 끄면 저장된 이메일을 삭제합니다.
- 표준 로그인 폼 필드와 자동완성 속성을 사용해 브라우저 비밀번호 관리자의 저장·자동완성을 지원합니다. 비밀번호를 앱 저장소에 보관하지 않습니다.

검증: 통합 테스트와 Pages용 프론트 빌드를 통과했습니다. 실제 브라우저 비밀번호 저장 동작은 브라우저 설정에 따라 달라지며, 자동 UI 테스트는 수행하지 않았습니다.

## v0.3.0 · 웹 배포 분리 — 2026-09-25

- GitHub Pages에서 화면을, Cloudflare Worker에서 API를 제공하도록 배포 구성을 추가했습니다.
- Pages에서는 계정마다 발급된 불투명 세션 토큰을 현재 브라우저 탭의 `sessionStorage`에 보관합니다. 비밀번호와 열품타 JWT는 브라우저에 저장하지 않습니다. 탭을 닫으면 다시 로그인해야 합니다.
- Worker 단독 주소의 기존 HttpOnly 쿠키 로그인은 유지합니다. Pages 출처의 API 요청만 CORS로 허용하고, 변경 요청에는 사용자별 세션과 CSRF 토큰을 요구합니다.

검증: 통합 테스트 12개, Pages API 주소를 넣은 프론트 빌드, Worker 번들 검사를 통과했습니다. 배포된 Worker의 Pages 출처 사전 요청과 타 출처 차단을 확인했습니다. 실제 계정의 Pages 로그인·타이머 제어는 `ypt.mcv.kr` DNS 및 HTTPS 연결 뒤에 확인해야 합니다.

## v0.2.0 · 그룹 동기화 개선 — 2026-09-25

- 그룹의 `mc`를 현재 인원이 아닌 정원으로 표시하고, 현재 인원은 조회된 멤버 수로 표시합니다.
- 잘못된 `im` 기반 공부 상태를 그룹 날짜 로그의 `dl.is`로 바꿨습니다. 앱에서 시작·정지한 실제 계정 검사에서 상태 변화가 확인됐습니다.
- 그룹의 완료 기록 `dl.sm`과 진행 중 시간을 구분했습니다. `dl.sm`은 실행 중 두 번의 조회에서 일정했고, 종료 후 늘었습니다. 진행 중 시간은 확인된 `dl.st`에서 매초 계산합니다.
- 선택한 그룹 멤버는 화면이 보일 때 15초마다 자동 확인합니다. 메인 타이머 상태가 바뀌면 그룹도 다시 확인합니다.
- 자동 동기화 주기를 10·15·30·60·120초 중에서 선택하고 브라우저에 저장할 수 있습니다. 기본값은 15초입니다.
- 타이머 화면의 종료 버튼을 `공부 끝내기`로 명확히 하고, 일시정지·재개의 차이를 안내합니다.
- 과목 색을 유효한 `co`/`c` 값으로 표시하고 화면 폰트를 Pretendard로 통일했습니다.
- Worker의 로그인 요청 오류를 수정하고, 열품타 응답 시계와의 차이를 타이머 표시에 보정했습니다. 종료 요청에 사용하는 원래 시작 시각은 변경하지 않았습니다.

검증: 실제 계정으로 로컬 로그인, 과목 색, 그룹 상태의 시작·정지 전환과 자동 갱신을 확인했습니다. 테스트 11개·빌드·Worker 번들 검사가 통과했습니다. 타이머와 앱의 약 0.5초 차이는 원격 조정 화면 지연과 HTTP `Date`의 초 단위 정밀도가 섞여 있을 수 있어 고정 보정값을 추가하지 않았습니다. Cloudflare Worker·D1을 배포하고 공개 화면·익명 세션·출처 검사를 확인했으며, 운영 주소의 실제 계정 로그인은 아직 검증하지 않았습니다. `ypt.mcv.kr` 연결은 대기 중입니다.

## v0.1.0 · 첫 검증판 — 2026-09-25

- 열품타 이메일 로그인, 실제 과목 조회, 앱·웹 타이머 교차 제어, 오늘·날짜별 기록, 가입 그룹·멤버 조회를 구현했습니다.
- Worker·D1에 웹 세션과 암호화된 열품타 JWT를 보관하고, 응답 유실 뒤 중복 시작·종료를 피하는 복구 흐름을 추가했습니다.
- 모바일 중심의 공부·기록·그룹 화면과 PC 레이아웃을 마련했습니다.

이 항목은 당시 `package.json`의 0.1.0 개발 상태를 소급해 정리한 것입니다. 별도 배포나 태그가 있었음을 뜻하지 않습니다.
