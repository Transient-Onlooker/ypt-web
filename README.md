# YPT Web

현재 버전: **v0.10.1 · 기록·동기화 안정화**. [변경 기록](docs/CHANGELOG.md), [버전 관리 기준](docs/VERSIONING.md), [배포 안내](docs/deployment.md)를 참고하세요. [ypt.mcv.kr](https://ypt.mcv.kr)에서 접속할 수 있습니다. API는 [Cloudflare Worker](https://ypt-web.junuh145858.workers.dev)가 제공합니다.

휴대폰과 PC에서 열품타 이메일 계정의 과목, 타이머, 공부 기록, 가입 그룹을 사용하는 웹 클라이언트입니다. 별도 서비스 가입이나 허용 목록은 없습니다. 화면은 React·Vite로 만들고 GitHub Pages에서 제공하며, Cloudflare Worker가 열품타 API를 중계하고 D1에 웹 세션과 타이머 상태를 보관합니다.

## 사용하기

1. [ypt.mcv.kr](https://ypt.mcv.kr)에서 열품타 **이메일 계정**으로 로그인합니다. 구글 로그인은 아직 웹 화면에 없습니다.
2. **공부**에서 앱의 과목을 선택해 타이머를 시작합니다. 일시정지는 열품타의 정지, 재개는 새 시작이며, **공부 끝내기**는 웹의 선택 과목을 해제합니다. **하루 목표**를 정하면 완료 기록 기준 진행률과 남은 시간을 볼 수 있습니다.
3. **공부**에서 **어제 기록 보기**를 누르면 오늘과 어제의 완료 시간을 비교할 수 있습니다. **요약 복사**는 오늘 완료 기록을 클립보드에 넣습니다. **기록**에서 날짜별 시간을, **그룹**에서 가입 그룹과 멤버의 상태를 확인합니다.

앱에서 시작한 타이머도 웹에 동기화됩니다. 화면을 닫아도 공부가 자동 종료되지 않습니다. 화면의 **자동 동기화**에서 확인 주기를 10·15·30·60·120초로 바꿀 수 있으며 기본값은 15초입니다.

휴대폰에서는 상단에 타이머 상태가 고정되고 아래 탭으로 공부·기록·그룹을 전환합니다. 탭을 바꾸면 화면 맨 위로 이동하며, 기록의 7일 그래프에서 날짜를 누르면 해당 날짜의 상세 기록으로 이동합니다. 최근 조회한 과거 기록은 같은 로그인 탭에서 5분간 재사용합니다. 기록이나 7일 그래프의 **새로고침/다시 불러오기**를 누르면 서버에서 다시 확인합니다. 탭을 오가도 7일 그래프와 그룹 멤버 현황이 유지되며, 그룹 현황은 화면 복귀 시 다시 확인합니다.

## 로컬 실행

Node.js 22 이상이 필요합니다.

```powershell
npm install
Copy-Item .env.example .dev.vars
```

`.dev.vars`의 `YPT_ENCRYPTION_KEY`를 무작위 32바이트의 base64 값으로 바꿉니다. 예를 들어 PowerShell에서 아래 명령으로 **키 값만** 생성할 수 있습니다. 생성한 값은 채팅이나 Git에 넣지 마세요.

```powershell
$bytes = New-Object byte[] 32
$rng = [Security.Cryptography.RandomNumberGenerator]::Create()
try { $rng.GetBytes($bytes) } finally { $rng.Dispose() }
[Convert]::ToBase64String($bytes)
```

`APP_ORIGIN=http://localhost:5173`을 유지하고 `npm run db:local`을 실행합니다. 터미널 두 개에서 `npm run dev:worker`와 `npm run dev`를 각각 실행한 뒤 `http://localhost:5173`에 접속합니다. 비밀번호·JWT는 출력하거나 로컬 파일에 저장하지 않습니다. D1에는 암호화된 JWT, 해시된 세션 토큰, 타이머 상태가 저장됩니다. 로컬 개발과 Worker 단독 주소는 HttpOnly·Secure·SameSite=Strict 쿠키를 사용합니다. Pages에서는 기본적으로 현재 탭의 `sessionStorage`에 불투명 세션 토큰을 보관합니다. 로그인 유지 옵션을 선택하면 별도의 HttpOnly·Secure·Partitioned 쿠키를 최대 30일간 사용합니다. 로컬 HTTP에서 Secure 쿠키의 예외 동작은 브라우저별로 차이가 있으므로, 운영 환경은 HTTPS를 사용합니다.

## 로그인 기억하기

로그인 화면의 **이메일 기억하기**를 선택하면 해당 브라우저의 로컬 저장소에 이메일만 저장합니다. 비밀번호는 앱이 저장하지 않습니다. 지원 브라우저에서는 로그인 성공 뒤 비밀번호 관리자에 저장 제안을 요청하고, 그 외에는 일반 자동완성 필드를 사용합니다. 저장 여부와 동작은 브라우저 설정에 따릅니다. Pages의 **이 기기에서 로그인 유지**를 선택하면 별도 HttpOnly·Secure·Partitioned 쿠키로 최대 30일간 새 탭에서 로그인 상태를 복원합니다. 선택하지 않으면 탭을 닫을 때 세션이 종료됩니다. 쿠키가 차단되면 화면에 안내가 표시되며 현재 탭에서는 계속 사용할 수 있습니다. 로그아웃하면 로그인 유지 쿠키와 연결된 세션을 폐기합니다.

## 현재 기능

- 열품타의 실제 과목을 조회합니다. 웹에서 시작한 타이머와 앱에서 시작한 타이머는 계정별로 상태를 동기화합니다. 시작 성공 뒤 인증 응답의 `p.st`를 다시 읽어 정확한 시작 시각을 보관하고, 확인할 수 없는 경우 종료에 추정 시각을 사용하지 않습니다.
- 일시정지는 열품타의 `stop`, 재개는 새 `start`입니다. 일시정지는 웹에 과목을 기억해 재개 버튼을 제공하고, 공부 끝내기는 웹 상태를 초기화해 다음 시작 때 과목을 고릅니다. 시작·재개 버튼을 누르면 서버가 앱 타이머가 정지 상태인지 다시 확인합니다. 일시정지 상태에서 종료할 때도 앱이 실제로 정지 상태인지 확인합니다. 앱이 꺼지거나 브라우저를 닫아도 자동 종료하지 않습니다. 화면 복귀 시 상태를 즉시 확인하고, 열린 화면에서는 선택한 주기로 확인합니다.
- 중복 클릭과 여러 탭은 D1의 버전 조건으로 막습니다. 응답 유실·통신 실패 뒤에는 같은 시작/종료 요청을 자동 재시도하지 않습니다. **열품타 앱에서 타이머를 실제로 정지한 뒤** 복구 버튼을 누릅니다. 처리 중인 요청은 최소 60초 동안 복구할 수 없으며, 복구 시 서버도 앱의 정지 상태를 확인합니다. 앱이 실행 중이거나 상태를 확인할 수 없으면 웹 상태를 초기화하지 않습니다.
- 기록은 API에서 확인된 날짜와 시간을 그대로 표시합니다. 과목별 구간이 누락되거나 잘못된 경우 시간을 0으로 추정하지 않고 미확인으로 표시합니다. 타이머 상태와 선택한 그룹 멤버는 선택한 주기로 확인하며, 가입 그룹 목록은 30초마다 갱신하고 직접 새로고침할 수 있습니다. 타이머와 그룹 목록의 이전 조회가 끝나기 전에는 자동 조회를 중복 실행하지 않습니다. 그룹의 `mc`는 정원으로 표시하고 현재 인원은 중복 ID를 제외한 멤버 수로 표시합니다. 중복 멤버의 값이 충돌하면 그 상태·시간은 미확인으로 둡니다. 멤버의 현재 공부 상태는 날짜 로그의 `is` 값으로 표시하며, 필드가 없으면 미확인으로 표시합니다. 실행 중 시간은 완료 기록과 구분해 1초마다 증가시켜 보여줍니다.
- 기록 화면에서 이전·다음 날짜와 오늘로 이동할 수 있습니다. 공부 중인 시간은 완료된 오늘 기록과 구분해 표시하며, 다른 화면과 브라우저 탭 제목에서도 타이머를 볼 수 있습니다. 그룹에서는 조회된 멤버 수와 멤버별 오늘 기록 시간을 보여주며 닉네임 검색과 시간·이름순 정렬을 제공합니다. 그룹 갱신이 지연되거나 실패하면 마지막 확인 시각과 오류를 표시합니다.
- 기록에서 확인된 완료 구간 중 가장 긴 시간과 공부한 과목 수를 보여줍니다. 가입 그룹의 소개·분류·방장 정보는 열품타 응답에 해당 문자열이 있을 때만 표시합니다. 이 추가 그룹 필드의 앱 화면 대조는 아직 남아 있습니다.
- 공부 화면의 하루 목표는 30분부터 12시간까지 선택할 수 있습니다. 목표는 이 브라우저에만 저장되며, 같은 브라우저의 다른 계정에서도 동일하게 보입니다. 달성률·남은 시간·초과 시간은 **완료된 오늘 기록**으로만 계산하고 실행 중인 세션은 합산하지 않습니다. 현재 타이머가 25·50·90분을 넘으면 작은 이정표를 표시합니다.
- **어제 기록 보기**는 누를 때만 날짜별 API를 조회합니다. 완료된 총시간만 비교하며, 어제 상세 기록으로 바로 이동할 수 있습니다. **요약 복사**는 날짜·완료된 총시간·확인된 과목별 시간만 클립보드에 넣습니다. 과목별 시간이 확인되지 않으면 ‘미확인’으로 적고, 실행 중 시간이나 계정 정보는 넣지 않습니다. 클립보드 기능은 브라우저가 지원하고 허용할 때만 동작합니다.
- 기록 화면의 **7일 기록 불러오기**를 누르면 오늘과 이전 6일의 완료 공부시간을 비교합니다. 확인된 날의 합계·평균·공부한 날 수·가장 많이 공부한 날을 보여줍니다. 조회하지 못한 날짜는 0시간으로 추정하지 않고 확인 불가로 표시하며, 확인된 날짜만 통계에 포함합니다. 날짜 막대를 누르면 그날의 상세 기록으로 이동합니다.
- 로그아웃은 현재 웹 세션을 해제합니다. 세션·열품타 로그인이 만료되면 로그인 화면에 이유를 표시합니다. 다시 로그인할 수 있도록 계정의 암호화된 열품타 JWT와 타이머 상태는 서버에 남습니다.

15초 이내 재시작의 기록 합치기는 웹에서 추정하지 않습니다. 재개 후 실행 타이머는 열품타가 다시 반환한 `p.st`를 사용하고, 오늘 완료 기록은 `dl.sm`·`dl.ls`를 표시합니다. 실제 계정으로 짧은 재시작 뒤 이 값들이 어떻게 바뀌는지는 아직 비교하지 않았습니다. 화면의 15초 자동 동기화 주기와 이 기록 규칙은 별개입니다.

## 검증

```powershell
npm test
npm run build
npm run check:worker
git diff --check
```

실제 API 조사 도구는 `scripts/`에 있습니다. 계정 입력은 로컬 터미널에서만 받으며 비식별 결과는 Git에서 제외한 `.ypt-local/`에 보존합니다. 실제 검증 결과와 한계는 [API 검증 기록](docs/api-validation.md)에 있습니다. 구글 계정의 로컬 검증 결과와 아직 구현하지 않은 범위는 [구글 소셜 로그인 조사](docs/google-social-probe.md)에 구분해 기록했습니다.

## 운영 배포

GitHub Pages가 화면을, Worker의 `/api`가 백엔드를 제공합니다. 운영 D1 마이그레이션과 `YPT_ENCRYPTION_KEY` secret을 적용했습니다. 사용자가 운영 주소에서 실제 계정 로그인과 타이머 시작·종료 성공을 확인했습니다. 운영 주소의 날짜별 기록·그룹 화면은 아직 직접 대조하지 않았습니다. `ypt.mcv.kr` 연결과 재배포 절차는 [배포 안내](docs/deployment.md)에 있습니다.
