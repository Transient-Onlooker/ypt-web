# 기능 후보와 검증 순서

2026-09-26 기준입니다. 아이디어 출처는 비공식 [deveworld/ypt_client](https://github.com/deveworld/ypt_client)의 `lib/screens/`와 `lib/ypt_api.dart`입니다. 참고 구현의 필드 해석은 실제 열품타 응답 검증과 별개입니다. 우리 앱에서 확인한 범위는 [API 검증 기록](api-validation.md)에 근거합니다.

| 상태·순서 | 아이디어 | 근거와 다음 확인 |
| --- | --- | --- |
| 적용 | 날짜별 과목 시간 막대그래프 | 참조 `stats_view.dart`에 과목별 막대가 있습니다. v0.6.0에서 오늘·날짜별 기록 화면에 적용했습니다. 확인된 과목 시간만 길이로 표시하고, 값이 없으면 막대를 표시하지 않습니다. |
| 적용 | 최근 7일 공부시간 추이 | v0.8.0에서 기존에 검증된 `/logs/day`를 이용해 오늘과 이전 6일을 버튼 클릭 시 조회합니다. 응답을 확인하지 못한 날짜는 비워 두고 합계에서 제외합니다. 날짜를 선택하면 해당 상세 기록으로 이동합니다. 새 열품타 API는 사용하지 않습니다. |
| 부분 적용 | 가입 그룹의 소개·분류·방장 표시 | 참조 `group_room_screen.dart`의 그룹 헤더에 있습니다. v0.7.0은 `/group/groups/v2`에 `sn`·`c`·`on` 문자열이 있을 때만 표시합니다. 실제 계정 응답 값과 앱 화면의 의미는 아직 대조하지 못했습니다. 현재 인원은 계속 조회된 멤버 수로 표시합니다. |
| 보류 | 웹 구글 로그인 | [로컬 검증](google-social-probe.md)에서 구글 Access token으로 열품타 JWT 발급과 인증 재조회가 성공했습니다. 그러나 소셜 경로가 새 제공자 ID로 열품타 계정을 만들 수 있고, 기존 앱 본계정과 일치하는지 확인되지 않았습니다. 서비스 데이터에 영향을 줄 수 있어 사용자 지시에 따라 웹 적용을 중단했습니다. |
| 4 | 그룹 둘러보기 | 참조 `ypt_api.dart`는 `/group/list-new-2`를 읽습니다. 실제 계정에서 목록·페이지·공개 범위를 검증하면 읽기 전용 탐색을 고려합니다. 그룹 가입·생성은 이 후보에 포함하지 않습니다. |
| 부분 적용 | 최장 세션·추가 시간·휴식 시간 | 참조 `stats_view.dart`가 요약 카드로 보여줍니다. v0.7.0은 검증된 완료 기록 `dl.ls[].sm`에서 **가장 긴 기록 구간**과 공부한 과목 수만 계산합니다. 열품타의 `mm`·`ad`·`rm` 필드 의미와 날짜 기준은 아직 검증되지 않아 최장 세션·추가 시간·휴식 시간으로 표시하지 않습니다. |
| 6 | 카테고리 내 순위 | 참조 `ypt_api.dart`가 `/logs/my-category-rank`, `/logs/category/member/ranks`를 사용합니다. 실제 계정에서 응답, 날짜·국가·카테고리 범위, 공개 정보 정책을 확인한 뒤 결정합니다. 첫 버전의 전체 랭킹 제외 범위를 유지합니다. |

우선순위는 사용자 가치와 현재 확인된 API 범위를 기준으로 정했습니다. 이 표는 구현 완료나 운영 배포를 뜻하지 않습니다. 기능을 추가할 때는 실제 계정 결과를 [API 검증 기록](api-validation.md)에 남기고 [변경 기록](CHANGELOG.md)에 구현·검증 범위를 따로 적습니다.
