# v0.11~0.21.3 직접 테스트 안내

[ypt.mcv.kr](https://ypt.mcv.kr)을 휴대폰에서 열고 실제 열품타 **이메일 계정**으로 로그인해 확인합니다. 비밀번호·JWT·CSV 원본·그룹 닉네임은 채팅에 보내지 않아도 됩니다. 열품타 앱과 비교가 필요한 단계만 앱을 함께 엽니다. PC 화면도 가능하면 마지막에 확인합니다.

## v0.21.3 모바일 계획 탭

휴대폰에서 하단 메뉴의 **계획**을 눌러 한 번에 계획 화면이 열리고 선택 표시가 이동하는지 확인합니다. 계획 항목 추가·완료·집중 선택 후 타이머, 오늘, 계획 탭을 오가며 내용이 유지되는지 확인합니다. 뒤로 가기·앞으로 가기로 계획과 오늘 화면이 복원되는지도 확인합니다. 타이머 실행 중 다른 탭에서 진행 표시가 계속 보이는지 확인합니다.

## v0.21.2 상단 상태와 계정 설정

상단 `대기 중` 상태와 밝기 전환 버튼이 모바일·PC에서 같은 줄에 있는지 확인합니다. **설정**을 열어 이메일 주소(이메일 계정) 또는 `Google로 로그인됨` 표시를 확인하고, 로그아웃을 누르면 로그인 화면으로 돌아가는지 봅니다. 다시 로그인하면 로그인 정보가 채워지고 새로고침 뒤에도 유지되어야 합니다. 기존 또는 새 탭에서 복원된 세션은 표시가 비어 있을 수 있습니다. 자동 동기화 간격도 설정 메뉴 안에 남아 있어야 합니다.

## v0.21.0 화면과 메뉴 분리

계획에서 뽀모도로 과제를 고른 뒤 타이머에서 뽀모도로를 실행합니다. 오늘 날짜가 갱신될 때 전날 과제가 타이머에서 사라지는지 확인합니다.

타이머 첫 화면에 타이머 카드만 있는지 확인합니다. PC 왼쪽 메뉴에서 오늘 요약·계획·날짜별 기록·통계·그룹을 각각 열고, 통계의 날짜를 누르면 선택 날짜 기록으로 이동하는지 확인합니다. 새로고침 뒤에도 URL의 선택 화면이 복원되고 브라우저 뒤로·앞으로 이동이 화면을 복원하는지 살펴봅니다. 휴대폰에서는 하단 타이머·오늘·기록·그룹 메뉴를 확인하고, 오늘/계획과 기록/기간 분석 보조 메뉴로 나머지 화면을 열어봅니다. 계획을 편집한 뒤 메뉴를 이동하고 돌아와도 오늘 계획이 유지되어야 합니다.

## v0.21.1 그룹 현황과 설정 메뉴

그룹 A를 열어 멤버와 인원수를 불러온 다음 그룹 B를 선택합니다. 그룹 B를 보는 동안 목록에서 A의 `현재 N명`이 남아 있고, 다시 A를 선택하면 이전 멤버 현황이 바로 보인 뒤 최신 조회 시각이 갱신되는지 확인합니다. 조회 실패 때도 마지막 멤버 현황이 사라지지 않아야 합니다. 그룹 A가 선택된 상태에서 목록의 A를 다시 누르거나 멤버 현황의 새로고침을 누르면 서버 조회가 시작되어야 합니다. 로그아웃 뒤 다른 계정으로 로그인하면 이전 계정의 인원수나 멤버가 잠시라도 표시되지 않아야 합니다.

상단 **설정**을 열어 자동 동기화 간격을 바꾸고, 선택값이 새로고침 뒤에도 유지되는지 확인합니다. 이 간격이 타이머·가입 그룹·현재 선택한 그룹 현황에 계속 적용되는지도 확인합니다. 설정 메뉴를 열고 닫을 수 있고 모바일 화면에서 화면 밖으로 잘리지 않아야 합니다.

## v0.20.3 브랜드 아이콘과 테마 색상

로그인 화면·사이드바·모바일 상단에 같은 Y 마크가 보이고 브라우저 탭에도 파비콘이 표시되는지 확인합니다. 휴대폰에서 홈 화면에 추가한다면 같은 마크가 아이콘으로 보이는지도 확인합니다. 라이트·다크 모드에서 공부·기록·그룹 화면을 한 번씩 확인합니다. 바탕과 카드가 흑백으로 유지되고, 네온 초록 없이 주요 버튼·공부 중 표시·진행 바만 차분한 세이지색으로 보이는지 살펴봅니다. 타이머 링과 오류 안내는 초록 테두리가 없어야 하며, 키보드 포커스 표시도 읽기 쉬워야 합니다.

## v0.20.2 Google 로그인 연결

운영 환경에 Google 로그인 버튼이 표시되는지 확인합니다. 앱에서 이미 Google로 로그인한 계정으로 웹에 로그인한 뒤, **타이머를 조작하기 전에** 과목 목록·가입 그룹·과거 날짜 기록이 앱의 기존 계정과 일치하는지 비교합니다. 모두 일치하면 짧게 시작·종료를 시험합니다. 자료가 비어 있거나 다르면 새 계정으로 연결됐을 수 있으므로 타이머를 조작하지 말고 결과만 알려주세요. 이메일·토큰·JWT는 보내지 마세요.

## v0.20.1 과목 선택과 그룹 갱신

로그인 상태에서 공부 화면의 과목을 바꾸고 새로고침합니다. 과목 선택이 마지막으로 고른 과목으로 복원되어야 합니다. 로그아웃 후 다른 계정으로 로그인하면 이전 과목을 자동 선택하지 않아야 합니다. 설정 메뉴에서 자동 동기화 간격을 10초로 설정하고 그룹 화면에서 그룹 목록과 선택한 멤버의 마지막 확인 시각이 약 10초 간격으로 갱신되는지 봅니다. 60초로 바꾸면 기존 타이머와 그룹 목록·멤버의 진행 중 조회가 즉시 중복되지 않아야 합니다.

## 먼저 확인할 핵심 동작

**먼저 로그인 실패 안내**: 비밀번호를 일부러 한 번 틀리게 입력하면 `열품타 계정 정보를 확인해 주세요.`가 표시되고, `열품타 로그인이 만료됐습니다`가 나오지 않아야 합니다. 그다음 올바른 비밀번호로 로그인할 수 있어야 합니다. 비밀번호나 서버 응답 원문은 보내지 마세요.

1. **공부 화면**: 앱에서 만든 과목과 색이 보이고, 휴대폰에서 타이머·목표·요약 카드가 가로 스크롤 없이 읽히는지 봅니다. 타이머가 `00:00:00`일 때 원판의 좌우 경계 밖으로 숫자가 잘리지 않는지도 좁은 화면에서 확인합니다. 하단 공부·기록·그룹 탭과 상단 상태가 화면을 스크롤해도 사용 가능한지 확인합니다. **타이머 이용 안내**를 펼쳤다 접고, 오류·복구 경고가 생긴 경우에는 안내를 접어도 경고가 보이는지 확인합니다.
2. **웹 → 앱 타이머**: 과목을 고르고 공부를 시작해 10초 이상 둡니다. 앱에서도 같은 공부가 보이는지 확인합니다. 웹에서 기록·그룹 탭으로 옮겨도 진행 시간이 보이고, 공부 탭으로 돌아와 **일시정지 → 재개 → 공부 끝내기**를 해 봅니다. 앱에서도 정지된 기록을 확인합니다. 버튼을 빠르게 두 번 눌러도 공부 구간이 중복으로 생기지 않아야 합니다.
   - **15초 이내 재개**: 30초 이상 공부한 뒤 일시정지 버튼을 누르고 15초 안에 재개합니다. 타이머가 0으로 초기화되지 않고 누적 시간에서 계속 올라가야 합니다. 서버 응답이 늦더라도 15초 기준은 버튼을 누른 시각부터 계산되어야 합니다. 새로고침하거나 다른 웹 탭에서 봐도 이어지는지 확인합니다. 다시 일시정지해 15초보다 더 기다렸다 재개하면 0초부터 시작해야 합니다. 이 동작은 웹 화면 표시만 이어 붙이며 열품타 완료 기록의 합산을 보장하지 않습니다.
3. **앱 → 웹 타이머**: 앱에서 공부를 시작하고 웹으로 돌아옵니다. 선택한 자동 동기화 주기 안에 웹 상단과 공부 화면에 앱 타이머가 나타나는지 봅니다. 웹에서 끝낸 뒤 앱에도 정지가 반영되는지 확인합니다. 타이머는 탭 전환·새로고침·휴대폰 화면 잠금 뒤에도 자동 종료되지 않아야 합니다.
4. **목표**: 기본 목표를 정한 뒤 **직접 입력**에서 45분처럼 다른 값을 적용하고 새로고침 뒤에도 남는지 봅니다. 15분 미만·24시간 초과 값은 적용되지 않아야 합니다. 공부 중에는 완료 기록 달성률과 무늬가 있는 **진행 중 포함 임시 예상치**가 구분되는지 봅니다. 공부를 끝낸 뒤 새로고침하면 임시 예상치가 사라지고 완료 기록 기준으로 갱신되어야 합니다.
5. **기록**: 오늘·어제·이전·다음 날짜를 이동하고 총시간·과목별 시간·과목 색을 앱 기록과 비교합니다. 과목의 시간순·이름순 정렬을 바꾸고, 모든 과목 시간이 확인된 날에만 비중이 보이는지 봅니다. 미확인 과목 시간은 0이 아닌 `미확인`이어야 합니다. 최근 **7일·14일**을 각각 불러와 날짜를 누르면 상세 기록으로 이동해야 합니다. **막대/달력** 표시를 바꿔도 같은 날짜가 나오고, 달력의 `?`와 `—`가 확인 불가·0시간을 구분하는지 봅니다. 요일·합계·일 평균·공부한 날 평균·일 중앙값·쉰 날·현재/최장 연속 기록을 확인하고, 14일·30일에서는 최근 14일이 모두 확인되면 직전 7일 ↔ 최근 7일 비교가 보이는지 봅니다. 조회 실패일은 0시간으로 표시하거나 비교에 합산하면 안 됩니다. 모든 과목 기록이 확인되면 **기간 과목별 공부**에서 누적 시간과 14일 앞뒤 7일 시간을 앱의 해당 과목 기록과 비교합니다. 하루 목표를 설정했다면 달성일 수와 연속 달성이 현재 목표 기준으로 표시되는지도 봅니다.
6. **CSV**: 기록에서 날짜별 **CSV 저장**과 7일·14일의 기간별 **CSV 저장**을 각각 누릅니다. 과목 시간이 전부 확인된 기간에는 **과목별 CSV 저장**도 누릅니다. 파일을 열어 날짜·완료 시간·과목 시간이 화면과 일치하는지 봅니다. 미확인 값이 있다면 기존 기간 CSV에서는 빈 시간과 `미확인` 상태여야 하고, 과목별 CSV 버튼은 나오지 않아야 합니다. 파일은 기기에 저장되며 서버로 업로드되지 않습니다.
7. **그룹**: 처음 그룹 화면에 들어왔을 때 가입한 모든 그룹에 `현재 N명`이 채워지는지 확인하고 앱의 실제 현재 인원과 `정원 N명`을 구분해 비교합니다. 공부 중·쉬는 중·미확인 필터의 숫자 합이 조회된 멤버 수와 같아야 합니다. 검색과 필터를 함께 적용하고, 시간 많은 순·공부 중 우선·이름순을 바꿔 봅니다. 앱에서 멤버 상태가 변하면 수동 새로고침과 자동 동기화 뒤 웹의 상태·막대가 바뀌는지 확인합니다. 그룹 목록 자체는 최소 60초 간격으로 갱신되므로 가입·탈퇴 직후에는 수동 새로고침이나 재진입으로 확인합니다.
8. **오늘의 계획**: 할 일 2개를 예상 시간과 함께 추가하고 하나를 완료로 표시합니다. 완료 개수·예상 시간·진행 막대가 맞는지 봅니다. 남은 할 일의 **집중**을 누르고 뽀모도로를 시작하면 메인 타이머에 제목이 보이고, 완료 표시·삭제 시 사라져야 합니다. 기록·그룹 탭을 다녀오거나 새로고침해도 유지되는지 확인합니다. 완료 항목 지우기와 개별 삭제도 시험합니다. 같은 탭을 날짜가 바뀔 때까지 열어 둔 경우 **어제 미완료 이어가기**로 완료하지 않은 할 일만 옮겨지는지 봅니다. 로그아웃하고 다시 로그인하면 계획이 사라져야 합니다. 열품타 앱의 실제 공부시간은 계획의 예상 시간 때문에 바뀌면 안 됩니다.
9. **뽀모도로**: 메인 타이머에서 일반/뽀모도로를 전환하고, 뽀모도로의 길이를 집중 5분·휴식 1분으로 설정합니다. 실제 열품타 과목을 골라 시작한 뒤 앱에서도 공부가 진행되는지 봅니다. 집중 종료 시 앱이 일시정지되고 휴식 종료 시 앱이 재개되어야 합니다. 집중 구간 수동 **잠시 멈춤/계속**도 앱과 같이 움직여야 하며, 휴식 구간의 잠시 멈춤은 휴식 카운트다운만 멈춥니다. 집중 시작·재개와 휴식 전환 직후 카운트다운이 서버 응답 전후로 튀지 않는지도 확인합니다. **공부 끝내기** 뒤에는 자동 재개가 없어야 합니다. 카운트다운 중 기록·그룹 탭 이동과 새로고침 뒤에도 같은 구간이 이어지는지 확인합니다. 화면 잠금·브라우저 종료 중에는 자동 전환하지 않고 웹으로 돌아와 상태 확인 후 전환해야 합니다. 앱에서 타이머를 별도로 조작한 경우 자동화를 멈추고 초기화 안내가 나오는지도 확인합니다.
10. **기간 회고 복사**: 7일과 14일을 각각 불러온 뒤 **기간 요약 복사**를 누릅니다. 붙여넣은 텍스트의 확인된 날짜 수·완료 시간·목표 달성일·과목 상위 3개가 화면과 일치해야 합니다. 조회 실패일이 있으면 날짜가 `미확인`으로 나오고 14일 앞뒤 비교는 미확인으로 남아야 합니다. 이메일·토큰·진행 중 시간은 없어야 합니다.
11. **반복 계획과 빠른 입력**: 현재 계획을 **반복 계획**에 저장하고, 할 일을 지운 뒤 불러옵니다. 완료 표시가 초기화되는지 봅니다. 같은 이름의 할 일을 이미 적었다면 중복이 생기지 않아야 합니다. **여러 할 일 빠른 입력**에 줄마다 하나씩 붙여넣고, 위에서 고른 예상 시간이 모두 적용되는지 확인합니다. 12개 초과나 80자 초과 항목이 들어가면 안 됩니다. 로그아웃·재로그인 뒤 반복 계획도 삭제돼야 합니다.
12. **과목 계획과 완료 기록**: 오늘 할 일 두 개를 같은 실제 열품타 과목에 연결해 예상 시간을 다르게 고릅니다. **과목 계획과 완료 기록**의 계획값이 두 예상 시간의 합인지 보고, 완료 기록은 앱의 그 과목 **전체** 완료시간과 대조합니다. 웹 또는 앱에서 공부를 마치고 자동 동기화 뒤 값이 갱신되는지 봅니다. 공부 중인 시간은 완료 기록에 더해지면 안 됩니다. 오늘 그 과목 공부를 하지 않았고 과목별 기록이 확인되었다면 `00:00:00`이어야 합니다. 과목별 기록이 미확인이라면 0 대신 `미확인`이어야 합니다. 반복 계획과 여러 줄 빠른 입력에도 과목 연결이 유지되는지 확인합니다.

## 시간이 되면 추가로 확인

- 자동 동기화를 10초와 60초로 바꿔 그룹·타이머 갱신 간격을 확인합니다. 앱과 웹을 오갈 때 1초 단위 타이머 표시는 화면에서 자체적으로 증가하지만 서버 상태 확인은 선택한 주기대로 이뤄집니다.
- 지원 휴대폰 브라우저에서 공부 중 **화면 켜두기**를 누르고 평소 화면 꺼짐 시간이 지나도 화면이 켜져 있는지 확인합니다. 다른 앱·탭으로 이동하면 화면 켜두기만 해제되고 타이머는 계속돼야 합니다. 지원하지 않는 브라우저에서는 버튼이 비활성이고 안내가 표시됩니다. 배터리·절전 설정에 따라 기기가 요청을 거부할 수 있습니다.
- 로그인 화면의 이메일 기억하기와 선택형 로그인 유지를 각각 확인하고 로그아웃 뒤 다른 계정 정보가 남지 않는지 봅니다.
- 밝은 화면은 흰 바탕·검은 글자, 어두운 화면은 검은 바탕·흰 글자로 보이고 브라우저 상단도 테마에 맞춰 흰색/검은색인지 로그인·공부·기록·그룹에서 확인합니다. 초록이 선택·실행·진행 표시 위주로 쓰이는지, 과목 색은 앱 값과 같은지, 테마가 새로고침 뒤 유지되는지도 봅니다. 공부 화면의 어제 비교 카드와 그룹의 중복 자동 확인 문구가 없는지도 확인합니다.
- PC에서 측면 메뉴와 2열 카드 배치를 확인합니다. 휴대폰은 세로/가로 방향 모두 가로 스크롤과 가려진 버튼이 없어야 합니다.

**최근 수정 회귀 확인**: 밝은 테마에서 타이머 원판과 `나의 집중 시간`이 흰 바탕·검은 글자이고 어두운 테마에서는 검은 바탕·흰 글자인지 확인합니다. 뽀모도로 집중·휴식 길이 옆의 `− / +`를 눌렀을 때 1분씩 바뀌고 최소·최대에서 더 바뀌지 않아야 합니다. 집중 중에는 `열품타 공부 중` 문구 없이 회차와 과목이 보이고, 휴식 중 상태 문구는 `휴식 중 · 열품타 일시정지`로 유지되며 과목명이 별도 줄에 읽기 쉽게 표시되어야 합니다. 이어서 공부 → 기록 → 그룹으로 이동하고 브라우저 뒤로가기 두 번, 앞으로가기 두 번을 눌러 탭이 순서대로 복원되는지 확인합니다. 각 탭에서 새로고침해도 같은 탭이 유지되어야 합니다.

오류가 나면 **어느 단계인지, 화면의 오류 문구, 기기/브라우저, 대략적인 시각**만 알려주세요. 민감한 계정 정보는 보내지 마세요.
