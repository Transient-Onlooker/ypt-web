# 변경 기록

이 문서는 개발 버전의 사용자에게 보이는 변경과 검증 범위를 기록합니다. 버전 번호는 `package.json`과 일치합니다. 운영 배포 또는 GitHub Release를 뜻하지 않습니다.

## v0.13.0 · 기록 저장과 현황 개선 — 2026-09-26

- 기록에서 선택 날짜와 최근 7일의 완료 공부시간을 CSV로 저장합니다. 미확인 과목·날짜는 빈 시간과 미확인 상태로 남기며, 과목명은 스프레드시트 수식으로 실행되지 않도록 처리합니다.
- 기록에 어제 바로가기·7일의 요일·확인된 최장 연속 공부일을 추가했습니다. 확인하지 못한 날이나 기록 없는 날은 연속 기록을 이어 붙이지 않습니다.
- 하루 목표에 현재 세션을 더한 임시 예상 달성률을 별도 무늬로 표시합니다. 실제 목표 달성률은 계속 완료 기록만 사용합니다.
- 그룹에 공부 중·쉬는 중·상태 미확인 비율 막대와 **공부 중 우선** 정렬을 추가했습니다. [직접 테스트 안내](manual-test-plan.md)에 이번 변경과 이전 화면 개선을 함께 검증하는 순서를 정리했습니다.

검증: CSV 안전 처리와 미확인 날짜·연속 기록 테스트를 포함해 총 24개 통과. TypeScript·Vite 빌드, `git diff --check` 통과. 실제 열품타 계정·휴대폰 화면 대조는 사용자가 확인해야 합니다.

## v0.12.0 · 타이머 안내·그룹 필터 개선 — 2026-09-26

- 타이머 조작 아래에 길게 보이던 설명을 **타이머 이용 안내**로 접었습니다. 통신 실패·상태 미확인·복구 지연 경고는 계속 즉시 보입니다.
- 그룹 멤버를 전체·공부 중·쉬는 중·상태 미확인으로 걸러 볼 수 있습니다. 닉네임 검색과 정렬을 함께 사용할 수 있고, 조회된 전체 인원과 현재 표시 인원을 구분합니다. 그룹 변경·로그아웃·인증 만료 시 필터를 초기화합니다.

검증: TypeScript·Vite 빌드, 기존 테스트 22개, `git diff --check` 통과. 실제 휴대폰 화면 조작은 수행하지 않았습니다.

## v0.11.0 · 집중 화면 디자인 개선 — 2026-09-26

- 인터넷의 실제 앱 화면 참고 자료와 모바일 내비게이션·접근성 지침을 검토하고, YPT Web에 맞게 독자적인 녹색 집중 화면을 구성했습니다. 타이머를 큰 중심 영역으로 강조하고 정보 카드·입력·버튼·내비게이션의 시각 체계를 통일했습니다.
- 모바일 하단 탐색을 안전 영역을 고려한 떠 있는 바 형태로 바꾸고, 의미가 분명한 선형 아이콘을 적용했습니다. 닫기·로그아웃 등의 작은 조작 영역도 키웠습니다. [참고 자료와 적용 원칙](design-direction.md)을 기록했습니다.

검증: TypeScript·Vite 빌드와 기존 테스트 22개 통과, `git diff --check` 통과. 실제 모바일 브라우저의 시각적·터치 검사는 수행하지 않았습니다.

## v0.10.1 · 기록·동기화 안정화 — 2026-09-26

- 과목 구간 로그가 불완전하거나 총시간은 있는데 구간 목록이 비어 있으면 과목별 시간과 최장 구간을 **미확인**으로 표시합니다. 잘못된 날짜도 기록으로 받아들이지 않습니다.
- 그룹 응답에 같은 멤버 ID가 여러 번 오면 한 명으로 세고, 중복 행의 공부 상태·시간이 충돌하면 해당 값은 미확인으로 표시합니다.
- 타이머·그룹 자동 조회는 이전 응답이 늦어도 중복 요청으로 결과를 계속 버리지 않습니다. 타이머 조작 직후 조회는 진행 중이던 자동 조회보다 우선합니다. 로그아웃 시 세션이 이미 만료됐다면 브라우저도 로그인 화면으로 돌아갑니다.

검증: 결함을 재현한 파서 테스트, API 통합 테스트, 느린 조회 경합 테스트를 포함해 총 22개 통과. 프론트 빌드와 Worker 번들 검사 통과. 불완전·중복 응답은 모의 입력이며 실제 열품타 계정에서 해당 입력을 관찰한 것은 아닙니다. 실제 브라우저 화면 조작은 수행하지 않았습니다.

## v0.10.0 · 어제 비교와 오늘 요약 복사 — 2026-09-26

- 공부 화면의 **어제 기록 보기** 버튼으로 어제와 오늘의 완료 공부시간을 비교하고, 어제 상세 기록으로 이동할 수 있습니다. 버튼을 누를 때만 검증된 날짜별 API를 조회하며 기존 5분 캐시를 재사용합니다. 다시 확인을 누르면 서버 값을 갱신합니다.
- **요약 복사** 버튼은 오늘 날짜·완료 총시간·확인된 과목별 시간만 클립보드에 복사합니다. 과목별 시간이 없으면 미확인으로 표시하고, 실행 중 세션과 계정 정보는 제외합니다. 브라우저 클립보드 기능이 허용되지 않으면 화면에 오류를 표시합니다.

검증: 요약 복사의 미확인 과목 처리 검사를 포함한 테스트 16개와 프론트 빌드 통과. 실제 모바일 브라우저의 클립보드 권한과 화면 배치는 직접 확인하지 않았습니다.

## v0.9.0 · 하루 목표와 7일 요약 — 2026-09-26

- 공부 화면에서 이 브라우저의 하루 목표를 30분~12시간 중 고를 수 있습니다. 오늘 완료 기록을 기준으로 달성률·남은 시간·목표 초과 시간을 보여주고, 25·50·75·100%에 따라 응원 문구가 바뀝니다. 실행 중인 세션은 완료 기록에 합산하지 않습니다. 설정은 같은 브라우저의 계정들이 공유하며 서버로 보내지 않습니다.
- 현재 타이머가 25·50·90분을 넘으면 공부 화면에 이정표를 표시합니다. 상태 갱신이 지연되거나 앱 상태가 미확인일 때는 숨깁니다.
- 이미 불러온 7일 기록에서 확인된 날의 평균, 공부한 날 수, 가장 많이 공부한 날을 추가 요청 없이 계산합니다. 응답을 확인하지 못한 날은 통계에서 제외합니다.

검증: 기존 통합 테스트와 프론트 빌드 통과. 실제 모바일 브라우저에서의 배치·목표 설정 동작은 직접 확인하지 않았습니다.

## v0.8.2 · 기록·그룹 갱신 개선 — 2026-09-26

- 이미 확인한 과거 날짜는 같은 로그인 탭에서 5분간 재사용해 기록 화면과 7일 그래프를 다시 열 때 불필요한 요청을 줄였습니다. 날짜별 새로고침과 7일 그래프의 다시 불러오기는 캐시를 건너뛰고 서버 값을 확인합니다. 로그인 변경·로그아웃·인증 만료 시 저장된 기록을 비웁니다.
- 7일 그래프는 다른 탭에 다녀와도 유지됩니다. 과거 기록을 다시 확인하는 동안에는 이전 값을 표시하고 갱신 중임을 알립니다.
- 그룹 탭으로 돌아왔을 때 멤버 목록을 비우지 않고 새 응답을 기다립니다. 다른 그룹을 선택하면 기존 그룹의 멤버가 섞여 보이지 않도록 했습니다.

검증: 기존 통합 테스트 14개와 프론트 빌드 통과. 실제 브라우저에서의 화면 전환 및 재조회 동작은 직접 확인하지 않았습니다.

## v0.8.1 · 모바일 사용성 개선 — 2026-09-26

- 좁은 화면의 상단을 브랜드·로그아웃과 타이머 상태 두 줄로 재배치하고, 스크롤 중에도 상태가 보이도록 했습니다. 하단 탭의 현재 위치 표시와 휴대폰 안전 영역 여백을 개선했습니다. PC 사이드 메뉴도 스크롤 중 보이도록 했습니다.
- 새로고침·날짜 이동·타이머 버튼의 터치 영역을 키우고, 탭 전환과 7일 그래프의 날짜 선택 후 화면 위치를 바로잡았습니다. 키보드 사용자를 위한 본문 바로가기 링크도 추가했습니다.
- 그룹 멤버의 자동 확인 안내가 고정된 15초 대신 현재 선택한 동기화 주기를 표시합니다. 그룹 목록 조회 실패와 그룹이 없는 경우의 안내를 구분합니다.

검증: 기존 통합 테스트 14개, Pages 빌드, Worker 번들 검사 통과. 실제 모바일 브라우저의 시각적 확인은 수행하지 않았습니다.

## v0.8.0 · 최근 7일 기록 — 2026-09-26

- 기록 화면에서 버튼을 누르면 오늘을 포함한 최근 7일의 완료 공부시간을 막대로 비교하고, 날짜를 눌러 상세 기록으로 이동합니다.
- 과거 6일은 검증된 날짜별 API를 최대 두 건씩 조회합니다. 응답 실패일은 확인 불가로 표시하고 확인된 날짜만 합산합니다. 자동으로 추가 조회하지 않습니다.

검증: 기존 통합 테스트 14개와 Pages 빌드 통과. 실제 계정의 7일 화면과 앱 기록 직접 비교는 아직 수행하지 않았습니다.

## v0.7.0 · 그룹·기록 요약 — 2026-09-26

- 가입 그룹의 응답에 소개(`sn`), 분류(`c`), 방장(`on`) 문자열이 있을 때 선택한 그룹 위에 표시합니다. 필드가 없거나 문자열이 아니면 생략합니다.
- 날짜별 기록에 공부한 과목 수와 완료 기록 `dl.ls[].sm`의 가장 긴 구간을 표시합니다. 열품타의 미검증 `mm` 필드를 최장 세션으로 해석하지 않습니다.

검증: 파서 회귀 검사를 포함한 테스트 14개, Pages 빌드, Worker 번들 검사 통과. 그룹 추가 필드의 실제 계정 값과 앱 화면은 아직 대조하지 못했습니다.

## v0.6.0 · 과목별 시간 시각화 — 2026-09-26

- 오늘의 공부와 날짜별 기록에서 과목별 완료 시간을 막대로 비교할 수 있습니다. 앱에서 가져온 과목 색을 사용하고, 시간이 미확인인 과목에는 막대를 그리지 않습니다.
- [기능 후보 문서](feature-ideas.md)에 비공식 참조 클라이언트에서 찾은 아이디어와 실제 API 검증 필요 범위를 정리했습니다.
- 웹 구글 로그인은 로컬 토큰 교환 성공과 별개로 보류했습니다. 새 제공자 ID로 열품타 계정이 생성될 수 있고 기존 앱 본계정과 일치하는지 확인되지 않았습니다.

검증: 통합 테스트 14개, Pages 빌드, Worker 번들 검사 통과. 과목 시간 그래프의 실제 화면 육안 검사는 아직 수행하지 않았습니다.

## v0.5.1 · 타이머 인증 만료 처리 — 2026-09-26

- 타이머 시작·정지·복구 중 열품타 인증이 만료되면 현재 탭과 로그인 유지 세션을 함께 폐기하고 로그인 화면으로 돌아갑니다.
- 짧은 일시정지 뒤 열품타가 이전 시작 시각을 반환하는 경우, 웹도 해당 시각을 그대로 사용하는 회귀 검사를 추가했습니다. 15초 기록 합치기 동작 자체는 실제 계정으로 검증하지 않았습니다.

검증: 통합 테스트 14개, Pages 빌드, Worker 번들 검사 통과.

## v0.5.0 · 선택형 로그인 유지 — 2026-09-25

- Pages 로그인 화면에 **이 기기에서 로그인 유지** 옵션을 추가했습니다. 선택하면 서버가 별도 HttpOnly·Secure·Partitioned 쿠키를 발급해 새 탭에서도 세션을 복원합니다. 최대 유지 기간은 30일이며 로그아웃하면 연결된 세션을 폐기합니다.
- 쿠키가 차단된 브라우저에는 안내를 표시하고 현재 탭의 로그인은 유지합니다. 비밀번호와 열품타 JWT는 브라우저에 저장하지 않습니다.
- 출처 제한·CSRF 검사·계정 분리·쿠키 만료·로그아웃·열품타 인증 만료를 통합 테스트로 확인했습니다.

검증: 통합 테스트 13개, Pages 빌드, Worker 번들 검사와 운영 배포를 통과했습니다. 실제 브라우저에서 로그인 유지 선택 후 새 탭 재접속 시 세션 복원과 로그아웃 후 해제를 사용자 확인으로 검증했습니다.

## v0.4.1 · 비밀번호 관리자 연결 — 2026-09-25

- 로그인 성공 뒤 지원 브라우저의 비밀번호 관리자에 저장 제안을 요청합니다. 저장 여부는 사용자가 브라우저에서 결정하며, 지원하지 않거나 저장을 거부해도 로그인은 계속됩니다.

검증: Pages용 프론트 빌드와 기존 통합 테스트를 통과했습니다. 사용자가 운영 Pages 주소에서 실제 계정 로그인·타이머 시작·종료 성공을 보고했습니다. 브라우저별 비밀번호 저장 제안 화면은 확인하지 않았습니다.

## v0.4.0 · 로그인 기억하기 — 2026-09-25

- 로그인 화면에서 이메일 기억하기를 선택하면 해당 브라우저에 이메일만 저장합니다. 선택을 끄면 저장된 이메일을 삭제합니다.
- 표준 로그인 폼 필드와 자동완성 속성을 사용해 브라우저 비밀번호 관리자의 저장·자동완성을 지원합니다. 비밀번호를 앱 저장소에 보관하지 않습니다.

검증: 통합 테스트와 Pages용 프론트 빌드를 통과했습니다. 실제 브라우저 비밀번호 저장 동작은 브라우저 설정에 따라 달라지며, 자동 UI 테스트는 수행하지 않았습니다.

## v0.3.0 · 웹 배포 분리 — 2026-09-25

- GitHub Pages에서 화면을, Cloudflare Worker에서 API를 제공하도록 배포 구성을 추가했습니다.
- Pages에서는 계정마다 발급된 불투명 세션 토큰을 현재 브라우저 탭의 `sessionStorage`에 보관합니다. 비밀번호와 열품타 JWT는 브라우저에 저장하지 않습니다. 탭을 닫으면 다시 로그인해야 합니다.
- Worker 단독 주소의 기존 HttpOnly 쿠키 로그인은 유지합니다. Pages 출처의 API 요청만 CORS로 허용하고, 변경 요청에는 사용자별 세션과 CSRF 토큰을 요구합니다.

검증: 통합 테스트 12개, Pages API 주소를 넣은 프론트 빌드, Worker 번들 검사를 통과했습니다. 배포된 Worker의 Pages 출처 사전 요청과 타 출처 차단을 확인했습니다. 실제 계정의 Pages 로그인·타이머 제어는 `ypt.mcv.kr` DNS 및 HTTPS 연결 뒤에 확인해야 합니다.

## v0.2.0 · 그룹 동기화 개선 — 2026-09-25

- 그룹의 `mc`를 현재 인원이 아닌 정원으로 표시하고, 현재 인원은 조회된 멤버 수로 표시합니다.
- 잘못된 `im` 기반 공부 상태를 그룹 날짜 로그의 `dl.is`로 바꿨습니다. 앱에서 시작·정지한 실제 계정 검사에서 상태 변화가 확인됐습니다.
- 그룹의 완료 기록 `dl.sm`과 진행 중 시간을 구분했습니다. `dl.sm`은 실행 중 두 번의 조회에서 일정했고, 종료 후 늘었습니다. 진행 중 시간은 확인된 `dl.st`에서 매초 계산합니다.
- 선택한 그룹 멤버는 화면이 보일 때 15초마다 자동 확인합니다. 메인 타이머 상태가 바뀌면 그룹도 다시 확인합니다.
- 자동 동기화 주기를 10·15·30·60·120초 중에서 선택하고 브라우저에 저장할 수 있습니다. 기본값은 15초입니다.
- 타이머 화면의 종료 버튼을 `공부 끝내기`로 명확히 하고, 일시정지·재개의 차이를 안내합니다.
- 과목 색을 유효한 `co`/`c` 값으로 표시하고 화면 폰트를 Pretendard로 통일했습니다.
- Worker의 로그인 요청 오류를 수정하고, 열품타 응답 시계와의 차이를 타이머 표시에 보정했습니다. 종료 요청에 사용하는 원래 시작 시각은 변경하지 않았습니다.

검증: 실제 계정으로 로컬 로그인, 과목 색, 그룹 상태의 시작·정지 전환과 자동 갱신을 확인했습니다. 테스트 11개·빌드·Worker 번들 검사가 통과했습니다. 타이머와 앱의 약 0.5초 차이는 원격 조정 화면 지연과 HTTP `Date`의 초 단위 정밀도가 섞여 있을 수 있어 고정 보정값을 추가하지 않았습니다. Cloudflare Worker·D1을 배포하고 공개 화면·익명 세션·출처 검사를 확인했으며, 운영 주소의 실제 계정 로그인은 아직 검증하지 않았습니다. `ypt.mcv.kr` 연결은 대기 중입니다.
