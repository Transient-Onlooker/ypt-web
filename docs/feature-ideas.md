# 기능 후보와 검증 순서

2026-09-26 기준입니다. 아이디어 출처는 비공식 [deveworld/ypt_client](https://github.com/deveworld/ypt_client)의 `lib/screens/`와 `lib/ypt_api.dart`입니다. 참고 구현의 필드 해석은 실제 열품타 응답 검증과 별개입니다. 우리 앱에서 확인한 범위는 [API 검증 기록](api-validation.md)에 근거합니다.

| 순서 | 아이디어 | 근거와 다음 확인 |
| --- | --- | --- |
| 1 | 날짜별 과목 시간 막대그래프 | 참조 `stats_view.dart`에 과목별 막대가 있습니다. 우리 앱은 과거 날짜의 `dl.ls` 합계와 과목 식별을 확인했으므로 기존 기록 화면 데이터로 시각화할 수 있습니다. 값이 없는 과목은 0으로 추정하지 않습니다. |
| 2 | 가입 그룹의 소개·카테고리·소유자 표시 | 참조 `group_room_screen.dart`의 그룹 헤더에 있습니다. 우리 앱의 `/group/groups/v2`에서 각 필드의 존재 여부와 의미를 비식별 조회로 확인한 뒤 추가합니다. 현재 인원은 `mc`가 아닌 조회된 멤버 수를 사용합니다. |
| 3 | 웹 구글 로그인 | [로컬 검증](google-social-probe.md)에서 구글 Access token으로 열품타 JWT 발급과 인증 재조회가 성공했습니다. 다음 단계는 웹 서비스 소유 Google OAuth 클라이언트 설정, Redirect URI·state/PKCE 처리, 계정 데이터가 기존 앱 본계정과 일치하는지 확인하는 것입니다. 운영 웹에는 아직 버튼이 없습니다. |
| 4 | 그룹 둘러보기 | 참조 `ypt_api.dart`는 `/group/list-new-2`를 읽습니다. 실제 계정에서 목록·페이지·공개 범위를 검증하면 읽기 전용 탐색을 고려합니다. 그룹 가입·생성은 이 후보에 포함하지 않습니다. |
| 5 | 최장 세션·추가 시간·휴식 시간 | 참조 `stats_view.dart`가 요약 카드로 보여줍니다. 우리 실제 응답의 필드·단위·기록 날짜 기준은 확인되지 않았으므로 현재 총 공부시간과 혼동하지 않도록 검증이 선행돼야 합니다. |
| 6 | 카테고리 내 순위 | 참조 `ypt_api.dart`가 `/logs/my-category-rank`, `/logs/category/member/ranks`를 사용합니다. 실제 계정에서 응답, 날짜·국가·카테고리 범위, 공개 정보 정책을 확인한 뒤 결정합니다. 첫 버전의 전체 랭킹 제외 범위를 유지합니다. |

우선순위는 사용자 가치와 현재 확인된 API 범위를 기준으로 정했습니다. 이 표는 구현 완료나 운영 배포를 뜻하지 않습니다. 기능을 추가할 때는 실제 계정 결과를 [API 검증 기록](api-validation.md)에 남기고 [변경 기록](CHANGELOG.md)에 구현·검증 범위를 따로 적습니다.
